# 临渊号曙光 (Abyssal Redemption)

远行星号 (Starsector) 0.98 强化学习舰船控制 mod。

## 简介

一艘来自"深井"的无人深空舰船——**临渊**，搭载维度驱动场战术系统与16组扫描激光传感器阵列，为 AI 自主作战提供实验平台。

## 内容

| 项目 | ID | 说明 |
|------|-----|------|
| 临渊 | `ARR_Linyuan` | 无护盾主力舰，45部署点，维度驱动场 |
| 临渊虚影 | `ARR_Linyuan_ghost` | 同参数，无碰撞箱（训练用） |
| 扫描激光 | `ARR_scanninglaser` | 16组内置传感器，测距用 |
| 深井星系 | Abyss system | 位于 (7000, -10000) |

## 依赖

- [MagicLib](https://github.com/MagicLibStarsector/MagicLib)
- [LazyLib](https://github.com/LazyWizard/lazylib)
- GraphicsLib（可选，扭曲特效）

## 构建

源码位于 `jars/src/`，将编译产物打包为 `jars/Abyssal Redemption.jar`。
